# KEF Controller 2.0.1

- 升级 pykefcontrol 至 1.0.1，适配 KefClient、设备身份、固件版本和事件队列，移除 requests 适配与直接依赖。
- 网络读取失败不再确认待机；网络不可达而未发送不再显示成功。
- 音量和切源操作检查目标版本，丢弃旧目标结果并停止过期重试。
- 托盘切换目标时清空旧状态，忽略旧目标事件。
- 网页状态值统一由控制器事件更新，轮询完成仅记录健康信息。
- backend_name 固定为 W2，兼容忽略旧配置字段，保存时移除。
- HTTPS 音箱在后台准备证书、客户端注册和 TLS 连接；快速待机使用新签名、有界 TLS 发送与回退，HTTP 音箱保留旧路径。传输写入成功仍不等于确认待机。
- 保留预热、目标/动作版本、取消门、消息泵外发送和原有预算。

验证：315 项单元测试通过；Ruff、compileall、pip check、Git whitespace 检查通过。本机 TLS 接收验证覆盖证书校验与带签名请求传输。安装器由 build.ps1 构建。

限制：未用真实 KEF 音箱验证锁屏、睡眠、合盖或关机；HTTPS 签名请求由上游设置至少 15 秒普通请求超时，不能用普通客户端替代紧急待机路径。签名复用 pykefcontrol 1.0.1 的内部 _auth 接口，后续升级需回归验证。
